# Scenario Practice

1. A teammate reports a problem related to git branches & merges. What do you inspect first, and how do you verify the cause?

2. A change involving git branches & merges works in your lab but fails in a shared environment. What evidence and checks would you collect before changing anything?

3. You must automate a repetitive git branches & merges task safely. How would you handle errors, least privilege, logging, and validation?

For every answer, cover diagnosis, safe remediation, verification, and prevention.
