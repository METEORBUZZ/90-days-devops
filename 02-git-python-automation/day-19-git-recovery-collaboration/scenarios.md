# Scenario Practice

1. A teammate reports a problem related to git recovery & collaboration. What do you inspect first, and how do you verify the cause?

2. A change involving git recovery & collaboration works in your lab but fails in a shared environment. What evidence and checks would you collect before changing anything?

3. You must automate a repetitive git recovery & collaboration task safely. How would you handle errors, least privilege, logging, and validation?

For every answer, cover diagnosis, safe remediation, verification, and prevention.
