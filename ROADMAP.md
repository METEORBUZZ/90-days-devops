# 90-Day DevOps Roadmap

Open each day's folder for learning objectives, practical task, scenarios, interview questions, MCQs, and reflection.

## Phase 1 — Linux, networking & scripting (Days 1–15)

- [ ] **Day 01: Linux Introduction & DevOps Workflow** — Linux kernel, distributions, shell, DevOps use cases
- [ ] **Day 02: Filesystem Hierarchy & File Commands** — /, /home, /etc, /var, /tmp, /opt; absolute and relative paths
- [ ] **Day 03: Reading, Searching & Text Processing** — Large files, pipes, stdout/stderr, redirection
- [ ] **Day 04: Users, Groups & sudo** — Users, groups, least privilege, sudo, account metadata
- [ ] **Day 05: Permissions & Ownership** — rwx permissions, numeric modes, ownership, umask
- [ ] **Day 06: Processes & Resource Usage** — PIDs, signals, CPU, memory, load, foreground/background
- [ ] **Day 07: Services & systemd** — Service lifecycle, unit files, boot, journal logs
- [ ] **Day 08: Packages & Software Installation** — Package managers, repositories, updates, dependencies
- [ ] **Day 09: Storage, Disk & Filesystems** — Mounts, disk usage, inodes, temporary storage
- [ ] **Day 10: Logs & Troubleshooting Basics** — Log levels, timestamps, journal, evidence-based debugging
- [ ] **Day 11: Networking Fundamentals** — IP, ports, TCP/UDP, DNS, routes, HTTP/HTTPS
- [ ] **Day 12: SSH & Secure Remote Access** — SSH keys, known_hosts, config, secure remote access
- [ ] **Day 13: Bash Fundamentals** — Shebang, variables, quoting, exit codes, command substitution
- [ ] **Day 14: Bash Conditions, Loops & Functions** — if/case, loops, functions, arguments, validation
- [ ] **Day 15: Linux Automation Mini-Project** — Combine host, disk, memory, process, and log checks

## Phase 2 — Git, Python & automation (Days 16–25)

- [ ] **Day 16: Git Fundamentals** — Git vs GitHub, working tree, staging, commits, .gitignore
- [ ] **Day 17: Git Branches & Merges** — Branching, merge, conflicts, safe collaboration
- [ ] **Day 18: GitHub & Pull Requests** — Remotes, pull requests, reviews, protected branches
- [ ] **Day 19: Git Recovery & Collaboration** — Revert vs reset, stash, tags, cherry-pick basics
- [ ] **Day 20: Python Fundamentals for Automation** — Variables, types, lists, dictionaries, loops, functions
- [ ] **Day 21: Python Files, JSON & Exceptions** — File handling, JSON parsing, exceptions, logging
- [ ] **Day 22: HTTP APIs & Python Requests Concepts** — HTTP methods, status codes, headers, JSON, timeouts
- [ ] **Day 23: Automation Quality & Testing** — Unit tests, dry-run, idempotency, linting, logging
- [ ] **Day 24: Python Automation Mini-Project** — API checks, disk checks, logs, structured reports
- [ ] **Day 25: Linux/Git/Python Review** — Review commands, Git workflow, automation, debugging

## Phase 3 — AWS cloud engineering (Days 26–40)

- [ ] **Day 26: AWS Fundamentals & Shared Responsibility** — Regions, Availability Zones, shared responsibility, Well-Architected
- [ ] **Day 27: IAM Users, Roles & Policies** — Identities, policies, roles, least privilege, MFA
- [ ] **Day 28: AWS CLI & Credentials** — Profiles, regions, temporary credentials, credential hygiene
- [ ] **Day 29: EC2 & Linux Cloud Instances** — Instances, AMIs, key pairs, lifecycle, pricing
- [ ] **Day 30: EC2 Security & Troubleshooting** — Security groups, SSH, status checks, instance reachability
- [ ] **Day 31: EBS, AMIs & Instance Storage** — Block storage, snapshots, persistence, backup
- [ ] **Day 32: S3 Fundamentals** — Buckets, objects, versioning, lifecycle, encryption
- [ ] **Day 33: S3 Security & Static Hosting** — Bucket policies, Block Public Access, CloudFront concepts
- [ ] **Day 34: VPC Fundamentals** — CIDR, VPCs, subnets, ENIs, IP addressing
- [ ] **Day 35: Routing, IGW & NAT** — Routes, internet gateways, NAT gateways, public/private routing
- [ ] **Day 36: Security Groups & Network ACLs** — Stateful vs stateless filtering, inbound/outbound rules
- [ ] **Day 37: AWS Monitoring & CloudWatch** — Metrics, logs, alarms, dashboards, agents
- [ ] **Day 38: AWS Cost Management & Tagging** — Budgets, tags, pricing dimensions, cleanup
- [ ] **Day 39: AWS CLI Automation & Security Review** — Repeatable CLI queries, dry runs, account safety
- [ ] **Day 40: AWS Mini-Project & Review** — Secured lab workload, architecture, cost, observability

## Phase 4 — Containers & CI/CD (Days 41–55)

- [ ] **Day 41: Containers & Docker Concepts** — Images, containers, registries, namespaces, cgroups
- [ ] **Day 42: Docker Images & Dockerfiles** — Base images, layers, build context, reproducibility
- [ ] **Day 43: Docker Run, Ports & Logs** — Port publishing, environment, lifecycle, logs
- [ ] **Day 44: Docker Volumes & Networking** — Bind mounts, named volumes, bridge networks, container DNS
- [ ] **Day 45: Docker Compose** — Multi-container definitions, environment, health checks
- [ ] **Day 46: Container Security & Image Scanning** — Non-root users, minimal images, vulnerability scanning
- [ ] **Day 47: Amazon ECR & Image Publishing** — Repositories, image tags, authentication, lifecycle policies
- [ ] **Day 48: GitHub Actions Fundamentals** — Workflow YAML, events, jobs, steps, runners
- [ ] **Day 49: CI Pipelines: Build & Test** — Linting, unit tests, artifacts, caching, failure gates
- [ ] **Day 50: CD Concepts & Deployment Strategies** — Continuous delivery/deployment, rolling, blue-green, canary, rollback
- [ ] **Day 51: Jenkins Fundamentals** — Controller/agents, jobs, credentials, plugins, security
- [ ] **Day 52: Jenkins Pipeline as Code** — Declarative pipeline, stages, post actions, parameters
- [ ] **Day 53: Secrets & Supply-Chain Security** — Secret stores, OIDC, dependency pinning, workflow permissions
- [ ] **Day 54: Deployment Automation & Rollback** — Environment config, health checks, approvals, artifacts
- [ ] **Day 55: CI/CD Mini-Project** — Code, test, scan, build image, publish, deployment plan

## Phase 5 — Terraform & Kubernetes (Days 56–70)

- [ ] **Day 56: Terraform Fundamentals** — IaC, providers, resources, HCL, plan/apply/destroy
- [ ] **Day 57: Terraform Variables, Outputs & Locals** — Types, defaults, outputs, locals, validation
- [ ] **Day 58: Terraform State & Remote Backend** — State, locking, remote storage, encryption, access controls
- [ ] **Day 59: Terraform Modules & Environments** — Reusable modules, dev/stage/prod separation
- [ ] **Day 60: Terraform Security & Team Workflow** — Plan review, CI validation, policy checks, imports, drift
- [ ] **Day 61: Kubernetes Architecture** — Control plane, nodes, API server, scheduler, etcd, kubelet
- [ ] **Day 62: Pods, Deployments & ReplicaSets** — Pod lifecycle, declarative state, replicas, rollout history
- [ ] **Day 63: Kubernetes Services & Networking** — ClusterIP, NodePort, LoadBalancer, DNS, selectors
- [ ] **Day 64: ConfigMaps, Secrets & Configuration** — Externalized config, mounts, environment, secret handling
- [ ] **Day 65: Probes, Resources & Scheduling** — Readiness/liveness/startup probes, requests/limits
- [ ] **Day 66: Kubernetes Storage & Stateful Workloads** — Volumes, PV, PVC, StorageClass, persistence
- [ ] **Day 67: Kubernetes RBAC & Security** — Service accounts, Roles, RoleBindings, non-root workloads
- [ ] **Day 68: Helm & Release Management** — Charts, values, templates, releases, rollback
- [ ] **Day 69: Kubernetes Troubleshooting** — Events, logs, exec, DNS, probes, image pull failures
- [ ] **Day 70: Kubernetes Mini-Project & Review** — App, Service, config, probes, resource controls, documentation

## Phase 6 — Monitoring, security & reliability (Days 71–80)

- [ ] **Day 71: Monitoring, Metrics & Observability** — Metrics, logs, traces, SLIs/SLOs, alert fatigue
- [ ] **Day 72: Prometheus Fundamentals** — Scraping, exporters, targets, labels, PromQL basics
- [ ] **Day 73: Grafana Dashboards** — Data sources, panels, variables, dashboard design
- [ ] **Day 74: AWS CloudWatch Logs & Alarms** — Log groups/streams, metric filters, alarm actions, retention
- [ ] **Day 75: Alerting & Incident Response** — Severity, escalation, runbooks, timeline, communication

- [ ] **Day 79: Performance & Capacity Troubleshooting** — CPU, memory, disk I/O, network, latency, bottlenecks
- [ ] **Day 80: Reliability Review & Game Day** — Bounded failure simulation, recovery, rollback, communication
