# 90 Days of DevOps Engineer Challenge

A day-by-day practical roadmap from Linux fundamentals to AWS, automation, CI/CD, infrastructure as code, Kubernetes, monitoring, security, and a final capstone.

## Daily format
- Theory: 30 minutes
- Hands-on lab: 20–30 minutes
- Assessment: 15–20 minutes
- Every day: 3 scenario questions, 4 interview questions, 4 MCQs, and a practical challenge.

## Roadmap phases
1. Days 1–15: Linux, networking and Bash
2. Days 16–25: Git, Python and automation
3. Days 26–40: AWS cloud engineering
4. Days 41–55: Docker and CI/CD
5. Days 56–70: Terraform and Kubernetes
6. Days 71–80: Monitoring, security and reliability
7. Days 81–90: Capstone, incident simulations and interviews

## How to use
1. Start at `01-linux-fundamentals/day-01-linux-introduction/README.md`.
2. Complete the lab and answer questions before looking up solutions.
3. Save sanitized evidence, update `PROGRESS.md`, and commit your work.
4. Do not commit secrets, credentials, private keys, Terraform state, or sensitive logs.

## Core tools
Ubuntu/Linux, Bash, Python, Git/GitHub, AWS IAM/EC2/S3/VPC/CloudWatch/CLI, Docker, Amazon ECR, GitHub Actions, Jenkins, Terraform, Kubernetes, kubectl, Helm basics, Prometheus, Grafana, Trivy.
